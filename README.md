# 拼豆图纸生成器

一个完全在浏览器本地运行的图片转拼豆图纸工具。图片不会上传服务器。

## 当前版本

界面版本：**v0.4.0**（页面左上角可核对）

- 上传 JPG、PNG、WEBP 图片
- 根据原图像素比例自动生成从低到高的网格精度选项，也支持手动网格
- LAB 感知色彩聚类提取主色
- MARD 280 色映射 / 原图真实色两种模式
- 使用完整 MARD 280 色卡，提高细节和原图相似度
- 可上传 MARD 基础色图片，校准屏幕/照片色卡刻度后再提取主色
- 每个网格单元保留对应色号，预览可切换显示
- CSV/JSON 导入自定义 MARD 实物色卡
- Floyd–Steinberg 抖动
- 多数投票滤波与边缘处理
- 带符号和十格参考线的网格预览
- MARD 颜色图例与材料统计
- 生成图纸后自动隐藏侧栏并适应窗口，也可手动恢复侧栏
- 提取主色和生成图解时显示阻塞式处理中弹窗，避免重复操作
- 导出带大字号色号的 PNG、JSON，以及每格带色号的单页整图矢量 PDF
- 低分辨率图片可一键打开 Bigjpg，高清化后重新上传

## 本地运行

直接用浏览器打开 `index.html` 即可运行，也可以使用任意静态服务器托管。

内置 `mard-palette.js` 是公开参考色卡整理版，屏幕 HEX 仅用于近似预览；如果你的 MARD 280 实物色号顺序或颜色不同，可在页面中导入自己的 CSV/JSON 色卡，下一次生成会使用导入的色号。

如果只有 MARD 色卡照片，可在“提取主色”中上传色卡图片进行 RGB 校准。校准会在当前页面内采样色块并沿用对应的 MARD 色号；校准完成后需要重新点击“开始提取主色”。

导出的 PNG 使用大网格和大字号色号，PDF 使用单页大画布的矢量文字。PDF 在手机预览中需要双指放大；如果打印时选择“适应页面”，整张图会被缩小，色号应以电子版放大查看或使用更大纸张打印。
