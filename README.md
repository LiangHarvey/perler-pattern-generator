# 拼豆图纸生成器

一个完全在浏览器本地运行的图片转拼豆图纸工具。图片不会上传服务器。

## 当前版本

界面版本：**v0.5.0**（页面左上角可核对）

- 上传 JPG、PNG、WEBP 图片
- 根据原图像素比例自动生成从低到高的网格精度选项，也支持手动网格
- LAB 感知色彩聚类提取主色
- MARD 280 色映射 / 原图真实色两种模式
- 使用完整 MARD 280 色卡，提高细节和原图相似度
- 按 MARD 标准色卡档位提取 24/48/72/96/120/144/216/264 色
- 每个网格单元保留对应色号，预览可切换显示
- Floyd–Steinberg 抖动
- 多数投票滤波与边缘处理
- 带符号和十格参考线的网格预览
- MARD 颜色图例与材料统计
- 上传设置、颜色图例和图纸按 Target 1 → Target 2 → Target 3 上下排列；生成后前两个 Target 保持显示，图纸自动适应窗口
- 提取主色和生成图解时显示阻塞式处理中弹窗，避免重复操作
- 导出带大字号色号的 PNG、JSON，以及每格带色号的单页整图矢量 PDF
- 低分辨率图片可一键打开 Bigjpg，高清化后重新上传

## 本地运行

直接用浏览器打开 `index.html` 即可运行，也可以使用任意静态服务器托管。

内置 `mard-palette.js` 是 MARD 280 标准色卡整理版。提取主色时，程序会先从完整色卡中按图片的颜色分布选择指定数量的 MARD 色号，再将每个网格匹配到这些色号；因此 24 色和 264 色会使用不同精度的 MARD 刻度。

“自动生成精度”会结合原图有效尺寸和 MARD 色数档位联动推荐，例如 150×200 格对应 MARD 144 色，最高档对应 MARD 264 色；也可以手动分别调整网格和色数。

导出的 PNG 使用大网格和大字号色号，PDF 使用单页大画布的矢量文字。PDF 在手机预览中需要双指放大；如果打印时选择“适应页面”，整张图会被缩小，色号应以电子版放大查看或使用更大纸张打印。
