# 拼豆图纸生成器

一个完全在浏览器本地运行的图片转拼豆图纸工具。图片不会上传服务器。

界面版本：**v0.5.9**（页面左上角可核对）

v0.6.0：新增“24色基础色优先替代”。生成后按用量由高到低检查非24色，仅当用量≥整图0.5%且≥10颗、与24色基础色的 CIEDE2000 色差≤6时替代；替代前后色号、数量和色差会在图例、材料清单、图纸底部、PNG/PDF及JSON中标注。

v0.5.8：为 CSS、MARD 色板及主程序增加版本参数，强制 GitHub Pages 和手机浏览器加载包含图纸底部用料清单的最新代码。

v0.5.7：在图纸底部增加随图导出的用料清单，包含色块、MARD 色号、色系、颗数、总豆数、图纸尺寸及每 10 格辅助线说明；网页预览、PNG 与单页 PDF 保持一致。

v0.5.6：依据 Zippland/perler-beads 的 291 色 MARD 映射校正色号与 RGB，并修复标准色卡分档中的编号格式、误录色号及 264 色档缺少 Q05 的问题。

- 上传 JPG、PNG、WEBP 图片
- 根据原图像素比例自动生成从低到高的网格精度选项，也支持手动网格
- LAB 快速筛选 + CIEDE2000 精确复核，提升 MARD 相近色号与中性色匹配准确度
- MARD SKU 色卡 / 原图真实色两种模式
- 使用图2/3提供的221组 HEX/RGB 作为颜色数值依据

- 每个网格单元保留对应色号，字体会按色号长度缩放并预留格内边距，预览可切换显示

- 顶部、底部、左侧、右侧均显示从 1 开始的行列坐标，并保留十格参考线和白色外边框

## 本地运行

直接用浏览器打开 `index.html` 即可运行，也可以使用任意静态服务器托管。

`mard-reference-221.js` 保存图2/3提供的221组 MARD HEX/RGB。提取主色时，程序先按照图1的 A～E、1～11 区域组合建立 24/48/72/96/120/144/216/264 SKU，再使用 CIEDE2000 感知色差匹配。SKU 中没有出现在图2/3的色号会提示并排除，不会使用旧色值或其他颜色代替。

“自动生成精度”会结合原图有效尺寸和 MARD 色数档位联动推荐，例如 150×200 格对应 MARD 144 色，最高档对应 MARD 264 色；也可以手动分别调整网格和色数。

导出的 PNG 使用大网格和大字号色号，PDF 使用单页大画布的矢量文字。PDF 在手机预览中需要双指放大；如果打印时选择“适应页面”，整张图会被缩小，色号应以电子版放大查看或使用更大纸张打印。

## GitHub Pages

在仓库 Settings → Pages 中，将 Source 设置为 `Deploy from a branch`，Branch 选择 `main` 和 `/ (root)`，保存后即可发布。
